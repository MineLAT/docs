## Información

Java es un lenguaje de programación orientado a objetos, es popular y "relativamente" simple de utilizar, debido a la existencia de mucha información decumentada sobre su uso y funcionamiento.

Es un buen lenguaje para empezar? No, pero si lo aprendes te será más fácil entender todo lo demás, así que despreocupate ya que al decir que no es ideal para empezar, no quiere decir que sea un lenguaje complicado, al contrario, puedes aprenderlo en menos de un día.

Lo importante es dominar los aspectos básicos, ya conforme vayas programando te encontrarás con problemas más complejos que requerirán investigación y te generarán mayor conocimiento de este lenguaje conforme pase el tiempo.

La mayoría de guías cubren de manera extensa las opciones de Java, por lo que puede ser agobiante para cualquier persona interesada en aprender a programar, aquí solo verás una explicación simple y sencilla para programar en Java.

## Bloque de código

En Java un bloque de código se ubica entre `{ }` y los comentarios se escriben después de `//` o entre `/** **/`, por ejemplo:

```java
{

}

{
	// Esto es un comentario
}

{
	/**
	 * Esto es otro comentario
	 **/
}
```
